\headerbox{Motivation \& Contributions}{name=motiv,column=0,row=0}{
\textcolor{seeblau100}{\textbf{Why Urdu?}}\\
LLMs are mostly evaluated on English. For low-resource, morphologically rich,
head-final languages such as \textbf{Urdu} (Indo-Aryan, $\sim$230M speakers,
Perso-Arabic script), it is unclear which grammatical phenomena multilingual
LLMs actually learn. Existing minimal-pair benchmarks (BLiMP, CLiMP, SLING,
RuBLiMP, TurBLiMP, BLiMP-NL, MultiBLiMP) lack broad coverage for Urdu.\\[4pt]
\textcolor{seeblau100}{\textbf{Our contributions}}
\begin{itemize}
\item First broad-coverage minimal-pairs benchmark for \textbf{Urdu syntax}.
\item \textbf{5{,}696} pairs, \textbf{10} phenomena, \textbf{19} paradigms.
\item Coverage of typologically distinctive phenomena: split ergativity,
      dative experiencers, honorific agreement, obliqueness, participial
      relatives, word-order variation.
\item \textbf{Two-round human validation} with 17 native speakers (1{,}077 pairs).
\item Evaluation of \textbf{20+ LLMs}: BERT, mT5, BLOOMZ, Granite, Gemma-3,
      LLaMA-3, DeepSeek-R1, Alif-Urdu, GPT-4o.
\end{itemize}
}

%====================================================================
% ROW 2 -- Linguistic phenomena
%====================================================================
\headerbox{Linguistic Phenomena}{name=phen,column=0,below=motiv,span=2}{
\begin{minipage}[t]{0.48\linewidth}
\textcolor{seeblau100}{\textbf{Universal \& core syntactic}}
\begin{itemize}
\item Subject--Verb Agreement (gender, number, person)
\item Noun--Adjective Agreement
\item Dative Object marking (\textit{ko})
\item Word-Order Variation in relative clauses
\item Participial Relatives
\end{itemize}
\vspace{2pt}
\textit{Example (gender agr., long distance):}\\
\foreignlanguage{arabic}{استانی سبق پڑھا کر آرام سے کرسی پر بیٹھ کر سوتی۔}\\
\textit{`After teaching, the teacher would sit and sleep.'}
\end{minipage}\hfill
\begin{minipage}[t]{0.48\linewidth}
\textcolor{seeblau100}{\textbf{Typologically distinctive (Indo-Aryan)}}
\begin{itemize}
\item Aspect Agreement (\textit{-ta:} / \textit{raha:} / \textit{cuka:})
\item Ergativity -- split system, \textit{ne} marking
\item Experiencer Subject -- dative \textit{mujhe}
\item Honorific plural agreement
\item Obliqueness (adj., noun, pronoun, plural, verb)
\end{itemize}
\vspace{2pt}
\textit{Minimal pair (Ergativity):}\\
\textbf{\textcolor{seeblau100}{$\checkmark$}}~\foreignlanguage{arabic}{پہرے‌دار نے تمام ماجرا راجا کو سنایا}\\
\textbf{\textcolor{schwarz60}{$\times$}}~\foreignlanguage{arabic}{پہرے‌دار نے تمام ماجرا راجا کو سناتا}\\
\textit{(ergative \textit{ne} requires perfective verb form)}
\end{minipage}
}


%====================================================================
% ROW 3 -- Method
%====================================================================
\headerbox{Method}{name=method,column=0,below=phen,span=2}{
\begin{minipage}[t]{0.31\linewidth}
\textcolor{seeblau100}{\textbf{1. Source corpora}}\\
\textbf{Urdu Treebank} (CLE, 7{,}854 sentences) -- syntactic patterns,
e.g.\ \texttt{(VC (VBF) (AUXP))} for aspect.\\[3pt]
\textbf{In-house Urdu corpus} -- regex extraction (e.g.\
\foreignlanguage{arabic}{جو \dots وہ \dots}) for sparse paradigms.
\end{minipage}\hfill
\begin{minipage}[t]{0.31\linewidth}
\textcolor{seeblau100}{\textbf{2. Pair generation}}\\
Rule-based perturbation of one minimal feature
(e.g.\ swap aspectual auxiliary, drop \textit{ko}, change verb gender)
to derive the \textbf{ungrammatical} counterpart.\\[3pt]
Manual review + typo cleaning per paradigm.
\end{minipage}\hfill
\begin{minipage}[t]{0.31\linewidth}
\textcolor{seeblau100}{\textbf{3. Human validation (PCIbex)}}\\
\textbf{17 native Urdu speakers}, two rounds.\\
Round 1: 20-pair training set.\\
Round 2: $\sim$190 pairs/annotator, 10 per paradigm, randomised,
forced-choice acceptability.\\
Validated subset: \textbf{1{,}077 pairs}.
\end{minipage}
}


%====================================================================
% ROW 4 -- Evaluation setup + headline results
%====================================================================
\headerbox{Evaluation Setup}{name=eval,column=0,below=method}{
\textcolor{seeblau100}{\textbf{Models (20+)}}
\begin{itemize}
\item \textbf{Encoder:} mBERT
\item \textbf{Encoder--decoder:} mT5-small, mT5-large
\item \textbf{Decoder:} Gemma-3 (1B/4B/12B/27B, pt+it), LLaMA-3-8B/70B,
      BLOOMZ-7B, Granite-3.3 (2B/8B), DeepSeek-R1-Distill-LLaMA-70B
\item \textbf{Urdu-tuned:} Alif-1.0-8B-Instruct
\item \textbf{Closed:} GPT-4o (Base, Grammar-Prompt, GP+CoT)
\end{itemize}
\textcolor{seeblau100}{\textbf{Metric}} -- sentence-level accuracy:
\[\text{Acc} = \tfrac{1}{N}\sum_{i=1}^{N}\mathbb{I}\!\left[
   \text{ppl}(s^{i}_{\text{good}}) < \text{ppl}(s^{i}_{\text{bad}})\right]\]
GPT-4o evaluated via two-choice prompting (\textit{explain-then-process}).
}

%====================================================================
% ROW 5 -- Findings + take-aways
%====================================================================
\headerbox{Key Findings}{name=findings,column=0,below=eval,span=2}{
\begin{minipage}[t]{0.31\linewidth}
\textcolor{seeblau100}{\textbf{Long-distance agreement is hard}}\\
Even LLaMA-3-70B fails when subject and verb are separated by intervening
clauses, e.g.\\
\foreignlanguage{arabic}{استانی سبق پڑھا کر \dots سوتی}\\
The longer the dependency, the more LMs default to local cues.
\end{minipage}\hfill
\begin{minipage}[t]{0.31\linewidth}
\textcolor{seeblau100}{\textbf{Size $\neq$ better}}\\
Within Gemma-3, 1B$\to$27B yields significant gains
(Wilcoxon, $p<0.05$). \textbf{But} Gemma-3-27B-pt rivals LLaMA-3-70B /
DeepSeek-70B -- \emph{no} significant difference among top models.\\
\textbf{Pretrained $>$ Instruction-tuned} on Gemma-3 (1B/4B/12B):
instruction tuning can \emph{hurt} grammatical sensitivity.
\end{minipage}\hfill
\begin{minipage}[t]{0.31\linewidth}
\textcolor{seeblau100}{\textbf{Phenomenon-specific}}
\begin{itemize}
\item Aspect, Dative: near-perfect (local cues).
\item Obliqueness: hard for adjectives \& masc.\ sg.\ nouns.
\item Subj--Verb gender: hardest, max 92.5\%.
\item Honorific: requires register knowledge.
\item UrBLiMP-SVA is \emph{harder} than MultiBLiMP-SVA.
\end{itemize}
\end{minipage}
}


%====================================================================
% ROW 6 -- Take-aways
%====================================================================
\headerbox{Take-aways}{name=take,column=0,below=findings,span=2}{
\begin{itemize}
\item UrBLiMP is the first broad-coverage minimal-pair benchmark for
      \textbf{Urdu syntax}.
\item Multilingual LLMs handle \textbf{local agreement} well, but
      struggle with \textbf{long-distance dependencies} and
      \textbf{morpho-syntactic case}.
\item \textbf{Grammar prompting} brings GPT-4o above human average.
\item \textbf{Continual pretraining on Urdu} (Alif-8B) beats its
      LLaMA-3-8B base.
\item Resources: \texttt{github.com/farahadeeba/UrBLiMP} -- open-source.
\end{itemize}
